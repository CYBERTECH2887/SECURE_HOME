PROJECT OVERVIEW & SPECIFICATIONS

What is SecureHome and why was it built?

SecureHome is an advanced and secure face-recognition based home surveillance system. It is designed to make residential and office security fully automated and offline without depending on third-party cloud APIs. The system scans visitors through a live webcam, authenticates recognized members, and instantly sends photo alerts to the administrator's email when an unknown visitor is detected.

🧠 AI & Machine Learning

Uses DeepFace (FaceNet) for facial feature extraction and Scikit-Learn SVM for accurate multi-class classification.

📹 Computer Vision

Powered by OpenCV and Haar Cascades for real-time video frame capture and fast face localization.

💻 Tech Stack & Languages

Backend: Python, Flask
Database: MySQL (Relational Schema)
Frontend: HTML5, CSS3 (Glassmorphism), JavaScript
